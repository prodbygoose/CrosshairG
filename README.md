CrosshairG v1.3

A clean crosshair overlay for Windows 10/11. No bloat, no tracking, just a crosshair.
Features

6 crosshair styles with full color and size customization
Live preview, second monitor support, mouse lock
Modern dark UI — settings auto-save between sessions

Hotkeys
| Ctrl+F5 | Open/close menu |
| Ctrl+F6 | Toggle crosshair |


Notes

Works best in Borderless Windowed mode — no performance difference on modern Windows
No data collected. Everything runs locally.
